The files were not modified. They are plain vector path data (a `vector` element with `path` children and no scripts), and each one was parsed to confirm that before it was copied.

## Source path pattern

`symbols/android/<name>/materialsymbolsrounded/<name>_24px.xml`

In this repository the file without a weight suffix is the weight 400 grade 0 variant, so the `_wght400_24px.xml` name that older docs mention does not exist. The app copy is `app/src/main/res/drawable/ic_<name>.xml`.
